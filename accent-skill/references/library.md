# Библиотека макетов

## Структура

235 макетов в `assets/library.pptx`. Каждый макет — слайд-образец с placeholder'ами вида `{{KEY}}`.

## Коды макетов

Формат: `A001`–`A235`

- A001–A020: Навигация, фокус, данные
- A021–A030: Модели (SWOT, BCG, Ансофф, PESTEL, и др.)
- A031–A040: Организация, проекты
- A041–A048: Финансы, бенчмарки
- A049–A052: Закрытие
- A053–A055: Обучение
- A056–A059: Изменения
- A060–A063: Отчёты
- A064–A066: Паузы
- A067–A069: Сценарии
- A070–A072: Методика
- A073–A075: Системы
- A076–A078: Результаты
- A079–A081: Исследования
- A082–A084: Инвестиции
- A085–A235: Специализированные и вариации

## Placeholder'ы

В текстовых полях образцов используются placeholder'ы:
- `{{TITLE}}` — заголовок
- `{{SUBTITLE}}` — подзаголовок
- `{{BODY}}` — основной текст
- `{{METRIC}}` — крупная цифра
- `{{LABEL}}` — подпись к метрике
- `{{ITEM1}}`–`{{ITEM6}}` — пункты списка
- `{{HEADER1}}`–`{{HEADER4}}` — заголовки колонок/секций
- `{{CELL1}}`–`{{CELL12}}` — ячейки таблиц

## Добавление макета

1. Создай слайд в library.pptx
2. Размести placeholder'ы
3. Запусти `python scripts/build_manifest.py`
4. Проверь `assets/manifest.json`
