# Порядок проверки

## 1. Аккуратно

`out.report.md`: ни одной ОШИБКИ, каждое ВНИМАНИЕ исправлено или пояснено.

## 2. Форма показывает мысль

Сверь `thesis` и макет:
- Если форма не говорит мысль без чтения — слайд не прошёл
- Контраст должен быть виден сразу
- Иерархия — главное крупнее
- Цепочка — направление чтения очевидно

## 3. Текст

- Не придуман, не пересказан
- Фактура из материала
- Выверенная по `language.md`

## 4. Сверка с deck.source

Каждая строка исходника есть в деке, ничего лишнего.

## Если ошибка — не объясняй, исправь

Не пиши "возможно, стоит…" — исправь и пересобери.
