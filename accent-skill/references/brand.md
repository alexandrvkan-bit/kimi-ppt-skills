# Бренд Акцент

## Шрифт

- **Основной:** Raleway
- **Fallback:** Arial, Helvetica, sans-serif
- **Заголовки:** Bold, 32–44 pt
- **Подзаголовки:** Medium, 20–24 pt
- **Основной текст:** Regular, 14–16 pt
- **Цифры:** Bold, 36–48 pt

## Цвета по умолчанию

| Роль | HEX | Использование |
|---|---|---|
| text | 1F1E1D | Основной текст |
| bg | FFFFFF | Фон |
| dark | 1F1E1D | Заголовки |
| surface | F6F5F1 | Карточки, блоки |
| accent | FFCC00 | Акценты, выделение |
| highlight | FFF7D1 | Светлый акцент |
| muted | 7A7872 | Вторичный текст |
| rule | E6E4DD | Разделители |
| accent_on_dark | FFCC00 | Акцент на тёмном |
| second | A3A199 | Дополнительный |

## Принципы

- Много воздуха
- Чёткая сетка
- Цифры — визуальный якорь
- Flat design, без теней
