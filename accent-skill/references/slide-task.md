# Карточка слайда

## Структура

Каждый слайд описывается карточкой:

```yaml
- thesis: "Главная мысль слайда — вывод, а не тема"
  rel: фокус | контраст | последовательность | иерархия | цепочка | обоснование | сравнение | количество
  work: "Что зритель поймёт, глядя на слайд"
  fields:
    KEY1: "Текст для поля 1"
    KEY2: "Текст для поля 2"
  items:
    - "Пункт 1"
    - "Пункт 2"
```

## Поля карточки

| Поле | Описание |
|---|---|
| `thesis` | Главная мысль — что зритель должен понять |
| `rel` | Отношение, которое форма должна показать |
| `work` | Работа слайда одной фразой |
| `fields` | Значения для полей макета |
| `items` | Пункты списка (если макет поддерживает) |
| `use` | Код выбранного макета |
| `alt` | Код альтернативного макета |
| `why` | Почему выбран этот макет |

## Отношения (rel)

- **фокус** — одна мысль в центре
- **контраст** — до/после, проблема/решение
- **последовательность** — порядок важен
- **иерархия** — главное и подчинённые
- **цепочка** — связь во времени или по причине
- **обоснование** — тезис + аргументы
- **сравнение** — два+ объекта рядом
- **количество** — числа и метрики

## Режимы

| Режим | Когда | Примеры |
|---|---|---|
| `read` | 1–3 человека, чтение без докладчика | Переговоры, приложения |
| `show` | 10–50, очно или онлайн | Презентации, лекции |
| `reference` | Справочный материал | Реестры, методички |
