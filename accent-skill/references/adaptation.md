# Правила адаптации макетов

## Заполнение полей

1. **Каждое поле из `slots` должно быть заполнено** — иначе пробел `[нужно: …]`
2. **Образец заменяется полностью** — не дополняется, не редактируется
3. **Цифры из материала** — образцовые цифры не остаются

## Списки

- Используй `items:` — движок сам выберет вариант на твоё число пунктов
- Максимум 6 пунктов на слайд
- Если больше — разбей на два слайда или сделай таблицей

## Пробелы

Когда фактов не хватает:
- **Текст:** `[нужно: уточнить дату запуска]`
- **Рисунок:** `figure: {gap: "нужна оценка NPV"}`
- **Данные:** оставь поле пустым, движок поставит пробел

## Цвет

- Движок красит в палитру автоматически
- Не указывай цвет в спецификации
- Исключение: статусы (зелёный/оранжевый/красный/серый)

## Размер

- Движок сам подбирает кегль
- Не указывай размер шрифта в спецификации
- Если текст не влезает — движок ужимает воздух или меняет вариант

## Проверка перед сборкой

```bash
python scripts/accent.py check spec.yaml
```

Проверяет:
- Все ли поля заполнены
- Есть ли `items` где нужны
- Нет ли ОШИБОК в макетах
