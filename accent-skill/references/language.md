# Язык и стиль

## Принципы

1. **Текст из материала** — слова и местоимения не меняются, меняется раскладка
2. **Главная мысль — вывод, не тема** — не «Проблемы», а «8 критических вызовов кластера»
3. **Конкретика** — числа, факты, даты вместо общих фраз
4. **Активный залог** — «создаём», «запускаем», а не «было создано»

## Запреты

- Не придумывать факты ради красоты
- Не использовать канцелярит («в целях», «в рамках», «в связи с»)
- Не писать абзацами — только пункты и короткие фразы
- Не дублировать заголовок в тексте

## Формулировки

| Плохо | Хорошо |
|---|---|
| В целях повышения эффективности | Повысить эффективность на 18% |
| Было проведено мероприятие | Провели сессию с 47 участниками |
| Рассматривается вопрос | Задача: сформировать портфель |
| В рамках программы | По программе |

## Числа

- Крупные цифры — без пробелов: 847 млрд, а не 847 000 000 000
- Проценты — с одним знаком: 12.5%
- Даты — кратко: 20–22 ноября 2026
- Диапазоны — тире: 2027–2030
