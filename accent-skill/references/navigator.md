# Навигатор: выбор макета по 5 шагам

## Шаг 1. Мысль и отношение

Одна строка: что зритель поймёт (`thesis`) и какое отношение должна показать форма (`rel`).

## Шаг 2. Названа модель — её макет

Если в тексте есть название модели → `python scripts/accent.py find <модель>`.

Канонические модели:
- Ансофф → A023
- BCG → A022
- SWOT → A021
- PESTEL → A024
- Жизненный цикл → A025
- Три горизонта → A026
- ADKAR → A027
- 7S → A028
- OKR → A029
- Путь клиента → A030
- SIPOC → A061
- VRIO → A062
- 9-box → A063
- ICAP → A054
- A3 → A069

## Шаг 3. По вопросу зрителя

`python scripts/accent.py nav` → группа → `python scripts/accent.py nav G05`.

Возьми **двух кандидатов** с нужным отношением. Выбери тот, чья форма без чтения текста говорит `thesis`.

## Шаг 4. Проверка макета

`python scripts/accent.py slots <код>`:
- Схема или ДАННЫЕ — каждое число из материала
- Нужно в материале — сверь с фактами
- Число элементов — границы
- ПУНКТЫ СПИСКОМ — `items:` если есть

## Шаг 5. Фактов не хватает — пробел

`[нужно: …]` в тексте, `figure: {gap: "…"}` для рисунка.

Не меняй форму, не придумывай факты.
