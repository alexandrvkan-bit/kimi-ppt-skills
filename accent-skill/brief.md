# Дизайн-бриф для презентации ТНФ

## Общее направление

- **Стиль:** Корпоративный, современный, чистый
- **Акцент на цифрах и данных** — крупные синие цифры
- **Минимализм** — много белого пространства, никакого мусора
- **Плоский дизайн** — без теней, без градиентов

## Палитра (точные цвета из референса)

- **Основной фон:** чистый белый `#FFFFFF`
- **Основной акцент:** яркий синий `#2196F3` (Material Blue)
- **Акцент тёмнее:** `#1976D2`
- **Заливка графиков/диаграмм:** светло-голубой `#E3F2FD` с прозрачностью 50%
- **Текст заголовков:** чёрный `#000000`
- **Текст основной:** тёмно-серый `#212121`
- **Текст вторичный:** серый `#757575`
- **Разделители/линии:** светло-серый `#E0E0E0`
- **Фон карточек/блоков:** `#F5F5F5` или `#FAFAFA`
- **Цветные статусы:** зелёный `#4CAF50`, оранжевый `#FF9800`, красный `#F44336`, серый `#9E9E9E`

## Типографика

- **Шрифт:** Raleway (уже в скилле)
- **Заголовки слайдов:** крупные, жирные, чёрные
- **Подзаголовки:** средний вес, серый
- **Основной текст:** тёмно-серый, удобочитаемый кегль
- **Цифры/метрики:** крупные, синие, жирные — визуальный акцент

## Композиция

- **Много воздуха** — большие отступы между блоками
- **Сетка:** чёткая, выровненная
- **Карточки:** с лёгким фоном (`#F5F5F5`), скруглённые углы
- **Разделители:** тонкие линии `#E0E0E0`
- **Иконки:** линейные, синие

## Особенности

- **Flat design** — никаких теней, никаких градиентов
- **Цифры как визуальный якорь** — крупные синие числа на белом фоне
- **Инфографика:** простые столбчатые/круговые диаграммы с синей заливкой
- **Статусы:** цветные пилюльки (зелёный/оранжевый/красный/серый)
- **Таблицы:** минимальные, с синими заголовками

## Референс

Material Design + корпоративный минимализм. Чисто, профессионально, акцент на данных.
